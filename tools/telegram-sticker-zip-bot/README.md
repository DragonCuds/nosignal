# ربات ساخت ZIP استیکر برای نوسیگنال

یک ربات کوچک و مستقل تلگرام (فقط Node 24، بدون هیچ بستهٔ npm). کاربر پیوند یک بستهٔ استیکر (`t.me/addstickers/NAME` یا فقط نام) یا هر استیکر را برای ربات می‌فرستد؛ ربات یک فایل ZIP برمی‌گرداند که همان را می‌توان در نوسیگنال از «افزودن بسته» آپلود کرد.

وقتی به کار می‌آید: سرور نوسیگنال به `api.telegram.org` دسترسی ندارد و وارد کردن مستقیم کار نمی‌کند. ربات را روی هر دستگاهی که به تلگرام می‌رسد اجرا کنید، ZIP را بگیرید و در نوسیگنال آپلود کنید.

## راه‌اندازی (۳ قدم)

1. در تلگرام با @BotFather گفتگو کنید، `/newbot` بزنید و توکن را بگیرید.
2. فایل `.env.example` را به `.env` کپی کنید و `TELEGRAM_BOT_TOKEN` را پر کنید (اختیاری: `ALLOWED_USER_IDS` با شناسهٔ عددی کاربران مجاز، جدا شده با کاما؛ `TELEGRAM_API_BASE` برای آینه). فایل `.env` را جایی منتشر نکنید.
3. اجرا:

```
node --env-file=.env bot.mjs
```

سپس در تلگرام به ربات `/start` بزنید.

## قالب ZIP

- `pack.json` با `slug`، `title` (حداکثر ۱۲۰ نویسه)، `thumb` و `stickers` (برای هر فایل: `file`، `emoji`، `sort`).
- فایل‌ها به‌صورت `001.webp`، `002.tgs`، `003.webm` و … با محتوای اصلی تلگرام، بدون تبدیل.
- محدودیت‌ها مطابق نوسیگنال: حداکثر ۱۲۰ استیکر، کل ZIP کمتر از ۱۲ مگابایت، هر فایل `.webp` تا ۵۱۲ کیلوبایت، `.webm` تا ۲۵۶ کیلوبایت، `.tgs` تا ۶۴ کیلوبایت. استیکرهای اضافه یا بزرگ کنار گذاشته می‌شوند و ربات تعداد آن‌ها را به فارسی می‌گوید.

## رفتار و امنیت

- long polling؛ حداکثر ۵ بسته در ساعت برای هر کاربر؛ پیام‌ها به فارسی.
- توکن هرگز در لاگ یا پیام خطا نمی‌آید؛ همهٔ درخواست‌ها timeout دارند و ریدایرکت دنبال نمی‌شود؛ نام بسته باید با `^[A-Za-z0-9_]{1,64}$` بخواند.
- فایل‌های بیش از ۲۰ مگابایت (سقف Bot API) دریافت نمی‌شوند.

## اجرای دائمی (نمونهٔ متن، چیزی نصب نمی‌شود)

اگر خواستید خودتان به‌صورت سرویس systemd اجرا کنید، نمونه:

```
[Unit]
Description=NoSignal sticker zip bot
After=network-online.target

[Service]
WorkingDirectory=/path/to/telegram-sticker-zip-bot
ExecStart=/usr/bin/node --env-file=/path/to/telegram-sticker-zip-bot/.env bot.mjs
Restart=on-failure
User=nobody

[Install]
WantedBy=multi-user.target
```

## آزمون

```
node --test test/bot.test.mjs
```

آزمون‌ها ربات را با یک سرور تلگرام ساختگی اجرا می‌کنند و ZIP خروجی را با اعتبارسنج‌های واقعی نوسیگنال (`apps/server/src/media/validation.ts`) می‌سنجند؛ به `unzip`، `ffmpeg` و `ffprobe` نیاز دارند.

طرح استیکرها حق سازندگانشان است؛ برای استفادهٔ شخصی و با رعایت شرایط تلگرام.
