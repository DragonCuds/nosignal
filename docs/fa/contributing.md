# مشارکت در پروژه

خوشحال می‌شویم کمک کنید. متن اصلی و کوتاه این راهنما در [CONTRIBUTING.md](../../CONTRIBUTING.md) است؛ اینجا توضیح فارسی آن آمده.

## قدم‌ها

1. مخزن را Fork کنید و یک شاخه (branch) بسازید.
2. نصب و ساخت: `npm ci && npm run build`
3. آزمون‌ها: `npm test` و `npm run test:security`. رفتار جدید باید آزمون داشته باشد (پوشهٔ `tests/`).
4. تغییرها را کوچک و متمرکز نگه دارید.
5. Pull Request بفرستید و توضیح بدهید چه چیزی را چرا تغییر داده‌اید.

## قواعد پروژه

- **رابط فارسی و راست‌به‌چپ اول است.** از سبک‌های موجود در `apps/web/src/styles/` پیروی کنید. بدون کادر یک‌پیکسلی.
- **بدون اینترنت خارجی.** برنامه باید موقع اجرا بدون هیچ CDN، فونت یا API خارجی کار کند. وابستگی (dependency) تازه را اول در یک Issue مطرح کنید.
- **هرگز راز (secret) کامیت نکنید:** فایل `.env`، دیتابیس، رسانهٔ کاربران.
- متن‌های رابط کاربری را به فارسی ساده و روان بنویسید.
- رمزنگاری را بدون بحث و آزمون تغییر ندهید و ادعای امنیتی بزرگ‌تر از واقعیت ننویسید.

## مشکل امنیتی

Issue عمومی باز نکنید. گزارش خصوصی بدهید: [امنیت](security.md).
