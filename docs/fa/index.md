# مستندات فارسی نوسیگنال (NoSignal)

NoSignal یک پیام‌رسان وب است که خودتان روی سرور خودتان نصب می‌کنید. گفتگوهای مستقیم و پیام‌های ذخیره‌شده سرتاسر رمز می‌شوند. برنامه برای اینترنت ضعیف ساخته شده و موقع اجرا به اینترنت خارجی نیاز ندارد.

- **می‌خواهم سرور راه بیندازم:** [راهنمای مدیر سرور](admin-guide.md)
