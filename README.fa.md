# نوسیگنال (تل) — NoSignal

یک پیام‌رسان وب شبیه تلگرام که خودتان روی سرور خودتان نصب می‌کنید و برای اینترنت ضعیف ساخته شده است. فقط یک سرور Node.js و یک فایل SQLite دارد و رابط آن فارسی و راست‌به‌چپ است. در زمان اجرا **به اینترنت خارجی نیازی ندارد**: بدون CDN، بدون فونت خارجی، بدون سرویس اعلان یا آمار شخص ثالث.

English: [README.md](README.md)

## امکانات

- **گفت‌وگوی مستقیم با رمزنگاری سرتاسری.** پیام‌ها و پیوست‌ها در مرورگر رمز می‌شوند و سرور فقط داده‌ی رمزشده را نگه می‌دارد.
- **پیام‌های ذخیره‌شده.** هر کاربر یک گفت‌وگوی خصوصی با خودش دارد که آن هم سرتاسر رمز است.
- **کانال‌های خصوصی.** کانال یک‌طرفه که با لینک دعوت عضو می‌شوید. کانال‌ها رمزنگاری سرتاسری **ندارند** و مدیر سرور می‌تواند پست‌ها را بخواند.
- **استیکر و گیف.** بسته‌های استیکر (از جمله متحرک TGS) و گیف.
- **ثبت‌نام به دلخواه شما.** پیش‌فرض با لینک دعوت است؛ با `OPEN_REGISTRATION=1` هر کس فقط با نام کاربری و رمز می‌تواند ثبت‌نام کند.
- **پشتیبان کلید آسان.** کلید رمزنگاری به‌صورت خودکار با رمز عبور قفل و پشتیبان‌گیری می‌شود تا در دستگاه جدید همه‌چیز خودکار باز شود (مدیر سرور در این حالت در اصل می‌تواند آن را باز کند)؛ حالت «امنیت بیشتر» کلید را از سرور برمی‌دارد و کلید بازیابی می‌دهد. جزئیات: [SECURITY.md](SECURITY.md).
- **امنیت حساب.** ورود دومرحله‌ای (TOTP) با کدهای بازیابی، کلید عبور (Passkey) و مدیریت نشست‌ها.
- **طراحی برای شبکه‌ی ضعیف.** فشرده‌سازی، همگام‌سازی ادامه‌پذیر، حجم کم، پیش‌نمایش تصویر، حافظه‌ی محلی و اتصال مجدد خودکار. جزئیات در [docs/WEAK-NET.md](docs/WEAK-NET.md).
- **نصب بدون اینترنت خارجی.** همه‌چیز همراه برنامه است و گواهی HTTPS محلی هم به‌صورت داخلی ساخته می‌شود (`TLS_MODE=auto`).

## نصب روی سرور (یک دستور)

روی سرور تازه‌ی اوبونتو ۲۲.۰۴/۲۴.۰۴ یا دبیان ۱۲، با کاربر root:

```sh
curl -fsSL https://raw.githubusercontent.com/<owner>/nosignal/main/install.sh \
  | sudo bash -s -- --domain tel.example.com --admin myname
```

دامنه ندارید یا سرور اینترنت بین‌الملل ندارد؟ فایل کاملاً آفلاین را بگیرید: `tar xzf tel-messenger-*-full.tar.gz && cd tel-messenger-*-full && sudo ./install.sh --ip-only --admin myname`. جزئیات: [docs/INSTALL.md](docs/INSTALL.md) و [INSTALL-FA.md](INSTALL-FA.md).

## شروع سریع (توسعه)

پیش‌نیاز: Node.js 24 و ffmpeg.

```sh
npm ci
cp .env.example .env     # SESSION_SECRET و TRUSTED_ORIGINS و DATA_DIR را تنظیم کنید
npm run build
npm run migrate
npm run user:add -- admin "Admin" --admin   # اولین حساب (مدیر) با خط فرمان ساخته می‌شود
npm run start
```

برای نصب واقعی [DEPLOYMENT.md](DEPLOYMENT.md) را بخوانید و برای راهنمای ساده‌ی فارسی [INSTALL-FA.md](INSTALL-FA.md) را.
